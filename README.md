# 摩托车手套终端系统 (Motorcycle Glove Terminal System)

**版本**: 2.0
**架构**: C++17 组件化设计
**平台**: ESP32-S3 (Freenove Board)

---

## 📋 项目概述

这是一个基于 ESP32-S3 的摩托车智能数据终端系统，用于实时采集、处理和存储骑行数据。系统采用主从式架构，终端作为主控单元，通过 UART 与左右手套（基于 STM32G03）进行通信，实现温度控制和数据采集。

### 核心功能

- **多传感器融合**: IMU (JY901)、GNSS (BE881)、光谱传感器 (AS7341)、气象站 (RS485)
- **手套温控**: 通过 UART 复用器与左右手套实时通信，实现 7 路温度闭环控制
- **数据记录**: SD 卡高速存储，支持实时数据流写入
- **无线连接**: BLE 广播与数据传输
- **实时处理**: FreeRTOS 多核任务调度，100Hz IMU 更新频率

## 🏗️ 系统架构

### 主从式架构 (Master-Slave)

```
┌─────────────────────────────────────────────────────────────┐
│                    ESP32-S3 终端 (Master)                    │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐   │
│  │  IMU     │  │  GNSS    │  │  AS7341  │  │  RS485   │   │
│  │ (JY901)  │  │ (BE881)  │  │  光谱仪  │  │  气象站  │   │
│  └──────────┘  └──────────┘  └──────────┘  └──────────┘   │
│  ┌──────────────────────────────────────────────────────┐  │
│  │              SD Card Storage + BLE                   │  │
│  └──────────────────────────────────────────────────────┘  │
└───────────────────────┬─────────────────────────────────────┘
                        │ UART (115200 bps)
                        │ via CD4052 Multiplexer
            ┌───────────┴───────────┐
            │                       │
    ┌───────▼──────┐        ┌──────▼───────┐
    │  左手套 (L)   │        │  右手套 (R)   │
    │  STM32G03    │        │  STM32G03    │
    │  7路温控     │        │  7路温控     │
    └──────────────┘        └──────────────┘
```

### 通信协议

- **物理层**: UART 8-N-1, 115200 bps
- **帧格式**: 二进制定长/变长帧，Sum8 校验
- **交互模式**: 请求-响应 (Request-Response)
- **时分复用**: CD4052 双路复用器切换左右手套

详见 [手套-终端通讯协议](docs/手套-终端通讯协议.md)

## 🔧 硬件组件

| 组件 | 型号 | 接口 | 功能 |
|------|------|------|------|
| **主控** | ESP32-S3 (Freenove) | - | 双核 240MHz, 8MB PSRAM |
| **IMU** | JY901 | I2C (via TCA9548A) | 9轴姿态传感器 |
| **GNSS** | BE881 | UART | GPS/北斗定位 |
| **光谱仪** | AS7341 | I2C | 11通道光谱传感器 |
| **气象站** | RS485 | UART | 温湿度、气压 |
| **存储** | SD Card | SD_MMC | 数据记录 |
| **通信** | BLE | - | 无线数据传输 |
| **复用器** | CD4052 | GPIO | 手套 UART 切换 |

## 💻 软件架构

### 组件化设计 (Component-Based Architecture)

采用严格的依赖倒置原则，实现业务逻辑与硬件解耦：

```
┌─────────────────────────────────────────────────────────┐
│  App Layer (lib/App_*)                                  │
│  ├── App_Glove      (手套管理)                          │
│  ├── App_IMU        (IMU 数据融合)                      │
│  └── App_System     (包调度器)                          │
└────────────────┬────────────────────────────────────────┘
                 │ 依赖接口
┌────────────────▼────────────────────────────────────────┐
│  Kit_Core (lib/Kit_Core) - 接口层                       │
│  ├── ITransport.h       (传输层接口)                    │
│  ├── IPacketHandler.h   (包处理接口)                    │
│  ├── IImuDriver.h       (IMU 驱动接口)                  │
│  └── ProtocolDef.h      (协议定义)                      │
└────────────────┬────────────────────────────────────────┘
                 │ 实现
┌────────────────▼────────────────────────────────────────┐
│  Driver_Hal (lib/Driver_Hal) - 硬件驱动层               │
│  ├── UartTransport      (UART 实现)                     │
│  ├── JY901Driver        (IMU 驱动)                      │
│  ├── SDStorageDriver    (SD 卡驱动)                     │
│  └── BLEDriver          (蓝牙驱动)                      │
└─────────────────────────────────────────────────────────┘
```

### FreeRTOS 任务分配

| 任务名 | 核心 | 优先级 | 频率 | 功能 |
|--------|------|--------|------|------|
| **T_RealTime** | Core 1 | 5 (High) | 100Hz | IMU 解算、手套通信 |
| **T_Sensors** | Core 0 | 3 (Mid) | 5Hz | AS7341、RS485 读取 |
| **T_Storage** | Core 0 | 2 (Low) | Event | SD 卡写入 |
| **T_System** | Core 0 | 1 (Low) | 10Hz | BLE 广播、状态监控 |

## 🚀 快速开始

### 环境要求

- **PlatformIO Core** >= 6.0
- **VSCode** + PlatformIO IDE 扩展
- **ESP32-S3** 开发板 (Freenove)
- **Python** >= 3.7 (用于上传工具)

### 编译与上传

```bash
# 1. 克隆项目
git clone <repository-url>
cd moto_terminal

# 2. 编译固件
pio run -e esp32-s3-terminal

# 3. 上传到开发板
pio run -e esp32-s3-terminal -t upload

# 4. 打开串口监视器
pio device monitor -b 115200
```

### 串口命令

系统支持以下串口命令（115200 bps）：

- `RESET` / `REBOOT` - 重启系统
- `STATUS` / `STAT` - 显示系统状态
- `HELP` / `?` - 显示帮助信息

## 🔬 开发规范

### C++17 编码标准

本项目严格遵循现代 C++17 嵌入式开发规范：

1. **零成本抽象**: 使用模板、`constexpr`、内联替代运行时开销
2. **编译期安全**: 使用 `static_assert`、`enum class`、`[[nodiscard]]`
3. **禁止动态内存**: 初始化后严禁 `new`/`malloc`，使用 `std::array` 或栈内存
4. **禁止异常**: 编译标志 `-fno-exceptions -fno-rtti`
5. **禁止 switch-case**: 使用查找表 + 函数指针替代

详见 [C++17 嵌入式开发规范](docs/C++17%20嵌入式开发规范与编码标准.md)

### 命名规范

- **类/结构体**: `PascalCase` (例: `GloveManager`)
- **函数/变量**: `camelCase` (例: `sendData`, `packetLen`)
- **私有成员**: `snake_case_` (例: `transport_`, `retry_count_`)
- **常量/宏**: `UPPER_CASE` (例: `MAX_BUFFER_SIZE`)

## 📊 技术规格

### 性能指标

- **IMU 更新频率**: 100Hz
- **手套通信频率**: 20Hz (左右手套各 10Hz)
- **数据记录频率**: 100Hz (IMU) + 5Hz (传感器)
- **BLE 数据传输**: 5Hz
- **系统延迟**: < 10ms (IMU 到存储)

### 内存使用

- **Flash**: ~1.2MB (含 Arduino 框架)
- **SRAM**: ~180KB (运行时峰值)
- **PSRAM**: 按需使用 (最大 8MB)

### 编译配置

```ini
platform = espressif32
board = freenove_esp32_s3_wroom
framework = arduino

build_flags =
    -std=gnu++17            # C++17 标准
    -O2                     # 优化级别
    -fno-rtti               # 禁用 RTTI
    -fno-exceptions         # 禁用异常
    -Wall -Wextra           # 警告级别
```
